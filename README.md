# Machine Learning Specialization - Study Code

This repository contains source code, Jupyter notebooks, and supporting files created while studying the [Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction) on Coursera, taught by Andrew Ng and the DeepLearning.AI team.

## 📚 About

The Machine Learning Specialization is a comprehensive series of courses covering foundational machine learning concepts, practical algorithms, and hands-on projects. This repository is organized by course and week, mirroring the structure of the specialization.

## 🗂️ Repository Structure

```
C1_W1/                  # Course 1, Week 1 notebooks and code
C1_W2/
...
requirements.txt        # Python dependencies
README.md               # This file
.gitignore
```

## 📝 Contents

- **Jupyter Notebooks:** Step-by-step labs, assignments, and practice exercises.
- **Python Scripts:** Utility modules and helper functions.
- **Course Coverage:**
  - Supervised learning (linear regression, logistic regression)
  - Neural networks and deep learning
  - Model evaluation and selection
  - Unsupervised learning (PCA, clustering)
  - Recommender systems
  - Practical tips for ML projects

## 🚀 Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/ngoc-minh-do/machine-learning-specialization.git
   cd machine-learning-specialization
   ```

2. **Set up the environment:**
   ```sh
   python -m venv env
   # On Unix or MacOS
   source env/bin/activate
   # On Windows
   env\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Open in Jupyter or VS Code:**
   - Launch Jupyter Notebook: `jupyter notebook`
   - Or open the folder in [Visual Studio Code](https://code.visualstudio.com/) for an enhanced experience.
